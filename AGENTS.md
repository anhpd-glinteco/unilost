# Session closeout

- At the end of each completed, scoped work session in this repository, commit and push only that session's task-owned changes on a `codex/` branch, then open a PR stacked on the task's direct predecessor.
- Update linked GitHub issues with the PR and verified evidence. Close an issue only when every acceptance criterion, including required external deliverables and CI, is complete; otherwise leave it open and state the remaining work.
- Preserve pre-existing dirty files: inspect and stage explicit task paths only. Never merge, deploy, or edit external documents/sheets unless the user asks.
